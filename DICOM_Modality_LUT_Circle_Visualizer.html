DICOM Modality LUT — Concentric Circle Visualizer

The left image shows stored grayscale pixel values. The right image applies a sampled Modality LUT to the same stored pixel values.

Image 1 — Stored Pixel Values

Each concentric ring represents a stored grayscale value. 255 is the innermost value and 0 is the outermost.

Concept: Stored Pixel Value → Display Gray
Ring value = grayscale intensity. 255 = white, 0 = black.

Image 2 — After Modality LUT

The same stored pixel values are mapped through the generated MLUT. The mapped output value controls the displayed grayscale.

Concept: Stored Pixel Value → MLUT → Output Pixel Value → Display Gray
The ring geometry is unchanged; only its grayscale value changes.
